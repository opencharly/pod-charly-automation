## The ninth node, and why it is deliberately still inline

`agent-control-operator-skill` declares **`type: agent`**, so the emitter publishes it into the
corpus's *agents* class, not its skills class — measured, and the verb disagreed with it:

```
$ grep -n "type: agent" charly.yml                    # THIS head, which is the whole point
76:        type: agent
$ git show origin/main:charly.yml | grep -n "type: agent" | head -1
1797:        type: agent                              # and the pre-move measurement, labelled as such
                                                     # (the 1,721 deleted lines above it are why the
                                                     # line number moved; round 1 rightly flagged the
                                                     # unlabelled version of this fence)
$ ls marketplace/automation/agents/ ; ls marketplace/automation/skills/ | grep -c control
agent-control-operator.md
0                                  ← 0 skill-tree projections, 1 agents-tree projection
$ # and the verb wrote it into the SKILLS tree anyway:
$ ls -d .agents/skills/agent-control-operator        # at extract time, before this choice
.agents/skills/agent-control-operator
```

That is a live instance of `opencharly/plugin-marketplace#34`: **`extract` has no agent branch.** The
settled ruling D8 puts an agent's body at `<repo>/.agents/agents/<name>.md`, the schema's comment
(`spec/schema/skill.cue:9`) puts it inside the skills tree, and `candywalk`'s one reader has no agent
branch at all — so *any* file this leg wrote for that node would either contradict the ruling or be
unreadable, and at the next regeneration the agent's body would **silently disappear from the
corpus**. So it is not moved here: its body stays inline, the verb's mis-placed directory was
**removed rather than shipped**, and it moves in the leg that implements the agent path. A repo
mid-move carrying both forms is explicitly sanctioned by the schema — *"A repo mid-move may carry
both, and the read order while both exist is the generator's contract"* — so this is a scoped
deferral with its finding filed, not a half-move.
